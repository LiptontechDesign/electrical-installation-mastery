# EPRA C2 & C1 Complete Study Pack — README

## What This Package Contains

This ZIP is a complete EPRA C2/C1 self-study package built for revision, understanding, calculation practice, oral-interview preparation and full mock-exam practice.

The package contains:

- **8 strengthened topic-by-topic study files**
- **1 full C1 mock exam with complete distinction-level answers**
- **1 full C2 mock exam with complete distinction-level answers**
- **1 high-priority 110-question recall and reinforcement bank**
- **this README file**

The recommended approach is to study the topic files first, then use the recall bank, then sit the mock exams under timed conditions.

# Recommended Final-Week Method

## First Pass

Read through the 110-question revision bank and mark questions you cannot answer confidently.

## Second Pass

Return to the relevant Step 1–8 file for each weak topic.

## Third Pass

Attempt the appropriate full mock exam under the 2-hour limit.

## Fourth Pass

Study only the questions you got wrong.

## Fifth Pass

Practice explaining the answers aloud as if an EPRA oral examiner is asking you:

- What is it?
- Why is it required?
- How does it work?
- What happens if it is wrong?
- How would you test it?
- What result would you expect?

# Important Standards Note

The files use BS 7671 material as a technical learning source where relevant.

The package also includes newer study awareness from the uploaded IET On-Site Guide updated to:

\[
\boxed{\text{BS 7671:2018+A4:2026}}
\]

However, EPRA is a Kenyan regulator.

For Kenya-specific legal, licensing and national-compliance questions, use:

- Kenyan legislation;
- EPRA requirements;
- applicable Kenya Standards;
- applicable utility requirements.

Do not automatically quote a UK-specific BS 7671 rule as Kenyan law.
