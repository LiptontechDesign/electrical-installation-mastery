# Module 6 and Module 7 learning structure

Updated 6 October 2026. The existing 25-module EPRA pathways remain in place.

Module 6 opens with **Complete Circuit Design with eFIXX — Parts 1 & 2**. Its ten lessons follow one connected example: first steps, design current, protective-device selection, rating factors, cable selection, voltage drop, earth-fault loop impedance, CPC sizing, RCDs and AFDDs. The introduction uses the user's original unlisted eFIXX video `42qk0TSwbAs`. The Part 2 CPC lesson is `GKdW9H_5NA4`. AFDD is included as an optional extension.

Ten focused sections follow: design brief/load planning; design current; demand/diversity; cable capacity/installation methods; rating factors; cable selection calculations; ring-final design; voltage drop; CPC sizing/fault withstand; prospective fault current/breaking capacity. Existing videos remain available, including the public introduction. The eFIXX rating-factor lesson is also included in its focused section.

Module 7 now opens with Gary Hayers's two-video assembly and dead-check sequence. It then separates safe isolation and supply arrangements, torque and secure terminations, and consumer-unit assembly. Its existing four videos retain that order. See [the Modules 7–9 introductions](connected-process-introductions.md).

The course now contains 355 catalogue lesson entries in 125 sections, plus 32 bundled supporting videos. Overview entries have distinct stable IDs, allowing learners to revisit a video and mark each occurrence independently. Video playback positions and timestamp notes continue to use the existing YouTube-ID storage; existing lesson notes, bookmarks and watched marks remain intact.

Curriculum revision 5 splits only former published Module 6/7 placements. Personal destinations and explicitly edited positions are preserved. Untouched supporting descendants follow their anchor; private additions without an applicable anchor stay in their chosen group. Existing section IDs remain valid for Undo. Archived/deleted entries stay inactive. A saved personal copy of an overview video remains available, including an AFDD video already placed in Module 5. New reads do not consume personal edit revisions or write account records.

Verify with `npm run test:design-learning`, `npm run test:curriculum`, `npm run test:placement-update` and the local browser fixture `npm run test:design-learning-browser`.
